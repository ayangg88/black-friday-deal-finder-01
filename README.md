# DealHound

[![make.fun bounty](https://make.fun/badge/black-friday-deal-finder-01.svg)](https://make.fun/bounties/black-friday-deal-finder-01)
[![reward](https://make.fun/badge/black-friday-deal-finder-01/ayangg88/black-friday-deal-finder-01/reward.svg)](https://make.fun/bounties/black-friday-deal-finder-01)

DealHound sniffs out real Black Friday prices with a fast, searchable deal board, honest verdicts, and verified store comparisons.

Run it with `node serve.ts`, then open [http://localhost:8080](http://localhost:8080). The 31 deals were checked on 27 November 2026 against public Tom’s Guide Black Friday roundups and live deal pages; each record keeps the named store, published price, source and check time. Prices can change, so verify at the store before buying.
